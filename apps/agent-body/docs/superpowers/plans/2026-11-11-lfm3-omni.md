# LFM3-Omni In-Browser Tier Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The English demo runs its whole conversation (voice in, photos in, text, voice out, tools) on one LFM3-Omni-2B model loaded from the official ONNX release, fully in-browser on WebGPU; IWSDK moves to 1.1.0-rc.2 and the avatar becomes ab-1.

**Architecture:** A new `src/agent/omni/` module set adapts two permissively-licensed reference engines — brvtl/act-it-out (MIT: graph sessions, chunked prefill, vision patching, MaskGIT depth decoding, iSTFT, Cache-API download) and Dudoxx/icedliquid (Apache-2.0: audio-encoder input, tool-call loop, worker protocol) — onto `LiquidAI/LFM3-Omni-2B-ONNX` (pinned commit). Generation runs in a Web Worker (mirroring `local-llm.worker.ts`); only text deltas and Float32 PCM chunks cross to the main thread. `src/agent/pipeline.ts` resolves omni vs the existing WebLLM path per settings + capability; brain/stt/tts gain an omni branch behind their existing seams.

**Tech Stack:** TypeScript, onnxruntime-web/webgpu ≥1.31, @huggingface/tokenizers, @huggingface/jinja, vitest (new), IWSDK 1.1.0-rc.2 / super-three 0.185, Web Audio.

**Spec:** `docs/superpowers/specs/2026-11-11-lfm3-omni-design.md`

## Global Constraints

- Reference code is adapted, with attribution: act-it-out (MIT), icedliquid (Apache-2.0). NOTICE + README entries are deliverables of Task 8.
- Model weights download at runtime from `https://huggingface.co/LiquidAI/LFM3-Omni-2B-ONNX/resolve/<pinned commit>` (pin the commit in `constants.ts`; act-it-out pins `7d6bd3fd59a0622e5ce7fefc141145a8bba1435a`). Nothing model-sized is committed to the repo.
- Graph bundle (decoder_q4f16 + vision_encoder_q8 + depth_decoder + codec_decoder + tokenizer/config JSONs) ≈ 2.1 GB; every status string must say what is happening. Sampler: greedy text; speech `audio_temperature=0.4`, `audio_repetition_penalty=1.2`, `audio_repetition_window=64`; prefill chunks ≤ 1024 tokens.
- Russian (`speechLanguage` not starting with `en`) never resolves the omni pipeline; no silent fallbacks — probe failures produce explicit panel messages.
- Photo path: capture only on anchored request (`requestsPhoto` unchanged); the frame exists for one request, never persisted; camera tracks stopped before the request completes (existing `perception.ts` guarantees must survive).
- UI copy fits `src/fonts.ts` charset; panel ids already exist — no new UIKitML rows required in this plan.
- Playback is interruptible only by explicit user stop (`hush()`); no barge-in.
- Every commit passes `npm run typecheck`.

## Review Focus

1. **Probe failure must stay loud**: a browser without WebGPU/`shader-f16` gets "Full local mode needs WebGPU…" and the WebLLM path — never a hung download. Test: Task 5 unit (`probeOmniCapability` mocked) + Task 8 panel copy.
2. **Language gates the omni tier**: `ru-RU` + local preset resolves WebLLM+Whisper, English resolves omni; switching language cancels an in-flight omni load. Test: Task 3 unit (`resolvePipeline`).
3. **Photo never persists**: an omni photo turn adds exactly one user chat record (text) and one assistant record; no image bytes in Dexie or history. Test: Task 9.
4. **`hush()` stops omni audio mid-utterance** and returns the avatar to neutral. Test: Task 7 unit (mock AudioContext queue) + emulator manual check.
5. **Context overflow drops the oldest exchange** instead of failing the turn. Test: Task 4 unit (prompt-budget trim) — mirrors both references' `dropOldestExchange`.
