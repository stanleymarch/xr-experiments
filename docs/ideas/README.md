# Идеи на будущее

Замыслы, которые **не входят в текущий каталог** и не обещаются на главной
странице. Они сохранены, чтобы не потерять концепции и их механику, но у них
нет ни кода, ни сроков, ни места в сборке `_site/`.

Активные опыты живут в [`apps/`](../../apps/):

- **REALITY//FIELD** — [`apps/reality-field`](../../apps/reality-field/);
- **WEATHER//ROOM** — [`apps/weather-room`](../../apps/weather-room/).

Камерные AR-опыты — в [`8thwall/`](../../8thwall/).

## Архив

- [CITY//ORBIT](city-orbit.md) — город как пространственная система, масштабируемая двумя руками.
- [SOUND//SPACE](sound-space.md) — звук как материал, замороженные звуковые скульптуры.
- [ECHO//ROOM](echo-room.md) — пространственная память комнаты, локальная перемотка времени.

Общее для всех трёх: тот же принцип «реальность как материал», что и у
активных опытов, но другие входные данные — город, микрофон, история
взаимодействий. Если возвращаться к ним, начинать стоит с брифа и runtime-
приёмки в IWER, как это сделано для REALITY//FIELD
([`docs/tasks/reality-field.md`](../tasks/reality-field.md)).
