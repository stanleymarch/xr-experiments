# ECHO//ROOM

Трёхмерный temporal debugger реальности: каждое действие оставляет след, пространство хранит ~60 секунд, клик по старому следу разворачивает временные слои.

Живое демо — `/experiences/echo-room/` на GitHub Pages.

## Что хранится

- **Траектория луча** — живая лента 600 точек, гаснет за 8 секунд.
- **Импульсы-тапы** — кольца ✦ в точке клика, живут 60 секунд (кольцевой буфер на 40).
- **Журнал** — все события `{t, kind, pos}` для реконструкции слоёв.

Клик рядом со старым ✦ (радиус 25 см) — это не новый импульс, а **inspect**: вокруг точки появляются 4 цветных слоя-призрака — состояния пространства в моменты −1с…−4с относительно импульса.

## Управление

Quest 3 / смартфон / десктоп: двигай лучом, кликай, кликай по старым кольцам. Кнопка — стереть историю.

## План

- **v0 (этот прототип):** всё выше. Готово.
- **v1:** слои как настоящие срезы ленты траектории (не журнал событий); scrub-ползунок времени внутри inspect; экспорт слоя в SOUND//SPACE-подобную скульптуру.
