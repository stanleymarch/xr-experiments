# SOUND//SPACE

Звук превращается в пространство: микрофон → Web Audio FFT → светящаяся 3D-лента времени перед тобой. Скажи «Staniverse» и заморозь фразу в скульптуру.

Живое демо — `/experiences/sound-space/` на GitHub Pages.

## Как выглядит звук

- **Речь** — нервные шипы (высокий spectral flux, холодный цвет).
- **Музыка** — гладкие волны с басовым завалом (тёплый синий).
- **Хлопок** — белая вспышка + расходящееся кольцо ударной волны.

Живой слой — впереди; три замороженных слоя уходят вглубь (оранжевый, зелёный, розовый). Вокруг собирается история последних минут.

## Управление

Quest 3 / смартфон / десктоп: кнопка **MIC** (разрешение спрашивается), **FREEZE** или pinch/тап/клик — заморозить момент, hold/squeeze — стереть историю. Bez микрофона работает демо-генератор (речь → музыка → хлопки по кругу).

## Техника

Только Web Audio API + троечная `PlaneGeometry` (220 × 96), скульптинг Z по спектру в реальном времени. Никакого сервера, AI и API — 0 ₽. `options.permissions.microphone = true` заранее декларирует доступ.

## План

- **v0 (этот прототип):** всё выше. Готово.
- **v1:** привязка замороженных слоёв к якорям комнаты (anchors) — история остаётся на месте, когда уходишь; амплитудная модуляция яркости по RMS; удаление одного слоя долгим наведением.
