XR TESTBED // 5 опытов

Quest 3 — главная платформа. Каждый опыт: смартфон AR + десктоп-симулятор. Стек: Three.js + XR Blocks, без сборки, деплой — GitHub Pages.

Требования: HTTPS + Chrome 136+. XR — на Quest 3 / Android XR. Микрофон и геолокация спрашивают разрешение на месте.
