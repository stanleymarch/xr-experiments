# CITY//ORBIT

Реальное окружение из OpenStreetMap — маленькая пространственная модель без единой 3D-модели: точки OSM становятся светящимися маркерами.

Живое демо — `/xrblocks/city-orbit/` на GitHub Pages.

## Режимы

- **Стол** — макет 1.2 м висит перед тобой, ты — белый конус в центре.
- **360°** — те же маркеры вокруг тебя в радиусе ~7 м.

## Управление

Quest 3 / смартфон AR / десктоп: наведи луч/взгляд → pinch/тап/клик → карточка (`название · тип · дистанция`, можно таскать). Кнопка `стол / 360°` переключает режим. **Разведи контроллеры** — радиус выборки перескочит 200 м → 1 км → 5 км, город буквально сожмётся между руками.

## Данные

Overpass QL: `node(around:R,lat,lon)[name]` с лимитом точек (60/120/200 по радиусам), `out body`. Публичные серверы Overpass перегружены, поэтому клиент держится аккуратно: POST вместо GET (длинные QL в URL режутся прокси с 406), гонка зеркал (выигрывает первый ответ: `overpass-api.de`, `overpass.kumi.systems`, `overpass.nchc.org.tw`), ретраи с бэкоффом 2/5/12 с и кулдауном зеркал на минуту после 429/504/таймаута, кэш в памяти на сессию. Нет сети → демо-квартал у Эрмитажа.

## План

- **v0 (этот прототип):** всё выше. Готово.
- **v1:** линии улиц (`way` с `highway`) как светящиеся рёбра; здания (`building`) — выдавленные призмы по высоте из тегов; кластеризация на 5 км чтобы маркеры не сливались.
