# CITY//ORBIT

> Настоящий город уменьшается до голограммы между твоими руками.

**Живое демо:** `/xrblocks/city-orbit/` на GitHub Pages.

## Идея

OpenStreetMap здесь не карта и не подложка. Именованные места становятся абстрактными световыми телами вокруг точки **YOU**: музей, кафе, университет, памятник. Макет можно положить на стол или раскрыть в 360° вокруг себя.

Наведи луч на точку — появится имя и расстояние. Вытяни место вверх — его карточка отделится от общего поля. Разведи две руки — радиус переключится **200 м → 1 км → 5 км**, и город буквально сожмётся между ладонями. Готовые 3D-модели не используются: только открытые данные, цвет, высота и ритм.

## Данные

Клиент делает ограниченные Overpass QL-запросы для культурных объектов, памятников, кафе, образования и других именованных POI. Порядок зеркал:

1. `https://maps.mail.ru/osm/tools/overpass/api/interpreter` — российский узел VK Maps / Mail.ru;
2. `overpass-api.de`;
3. `overpass.kumi.systems`;
4. `overpass.nchc.org.tw`.

Первый успешный ответ выигрывает; остальные запросы отменяются. Есть таймаут, cooldown после перегрузки и кэш на сессию. Если ни один сервер не ответил, появляется явно помеченный демонстрационный квартал у Эрмитажа — опыт остаётся работоспособным, но не притворяется live-данными.

Данные OpenStreetMap: © OpenStreetMap contributors, ODbL. Публичные Overpass-инстансы используются умеренно.

## Режимы и управление

- **СТОЛ** — 1,2-метровая орбитальная схема фиксируется перед пользователем;
- **360°** — те же данные окружают пользователя;
- **select / pinch / click** — выбрать POI и поднять карточку;
- **две руки в pinch и разведение** — изменить географический радиус;
- HTML-кнопки и координаты остаются fallback для телефона и десктопа.
