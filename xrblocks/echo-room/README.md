# ECHO//ROOM

> Пространство помнит последние 60 секунд и позволяет отматывать время локально.

**Живое демо:** `/xrblocks/echo-room/` на GitHub Pages.

## Идея

Движение указателя не исчезает сразу: его траектория остаётся полупрозрачной световой нитью. Tap рождает импульс ✦. Через минуту комната заполнена недавней историей, но не превращена в видеозапись — сохранены именно пространственные действия.

Нажми на старый ✦, и вокруг этой точки раскроются четыре прошлых состояния:

```text
NOW
−1 sec
−2 sec
−3 sec
−4 sec
```

Это temporal debugger реальности: можно изучить, что происходило здесь, не отматывая весь мир и не используя вторую руку.

## Что хранится

- кольцевой буфер траектории луча: 600 точек, живое окно 8 секунд;
- импульсы с мировой позицией и временем жизни до 60 секунд;
- компактный журнал движения для реконструкции локальных слоёв;
- выбранная точка и четыре окна времени вокруг неё.

Траектория пишется в продублированный буфер, а рисуется через `setDrawRange`: так `Line` не тянет сегмент через весь буфер при завороте кольца и не оставляет вертикальных шлейфов от погашенных точек. Временные слои собираются из журнала каждый кадр, но только для выбранной точки — это 60 секунд истории и четыре тонкие линии.

Сырые события остаются в памяти текущей вкладки и никуда не отправляются.

## Управление и платформы

Quest использует луч руки или контроллера; телефон и десктоп проходят через тот же select API XR Blocks — в симуляторе это клик мышью в режиме User. Select в пустом месте создаёт ✦, select рядом со старым импульсом (радиус 25 см) раскрывает время. Кнопка «стереть историю» очищает следы, импульсы и временные слои. При `?test=1` включается automation-режим XR Blocks: симулятор без рук и ретиклов, готовый к эталонным кадрам.
