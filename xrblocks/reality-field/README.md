# REALITY//FIELD

> Комната перестаёт быть фоном и становится интерактивным физическим полем.

**Живое демо:** `/xrblocks/reality-field/` на GitHub Pages.

## Идея

Стены, стол, пол и окружающая геометрия входят в произведение наравне с виртуальными частицами. Взмах руки выпускает импульс: он встречает поверхность, вспыхивает, расходится светящейся волной и меняет всё поле. Важен не отдельный «объект в AR», а ощущение, что сама комната обрела невидимую до этого физику.

- pinch накапливает заряд;
- открытая ладонь отталкивает частицы;
- кулак притягивает;
- две руки растягивают поле;
- select / клик выпускает обычный импульс.

## Два слоя реальности

**DEBUG REALITY** показывает техническое зрение системы: синтетическую или живую depth-геометрию, fallback-плоскости, визуализацию рук и лучей, нормали последних столкновений и FPS.

**DREAM REALITY** увеличивает светящиеся частицы, ослабляет возврат к исходной решётке и оставляет медленные волны и силовые линии. Это тот же runtime, а не другая сцена: переключатель меняет способ видеть одни данные.

## Платформы

| Платформа | Взаимодействие |
|---|---|
| Quest 3 | руки и контроллеры; pinch / palm / fist / two-hand spread; живой depth mesh, если браузер его отдаёт |
| Смартфон | WebXR AR/select при поддержке; тап и fallback-геометрия при отсутствии depth |
| Десктоп | официальный XR Blocks simulator; мышь/select, синтетическая depth-комната, позы рук |

## Реализация

`options.enableDepth()` создаёт обновляемый `xb.depth.depthMesh`; импульс рейкастится в него и получает мировую нормаль. Если mesh ещё не прогрелся или не поддерживается, используются пол и сферическая граница комнаты. Поле — один `THREE.Points`, силовые связи — один `LineSegments`, вспышки — переиспользуемый пул шейдерных колец.

Depth mesh сейчас определяет место и нормаль удара; отдельные частицы остаются дешёвой CPU-системой с границами комнаты. Полная per-particle коллизия с шумным живым mesh потребует Rapier и отдельной проверки производительности на Quest 3.
