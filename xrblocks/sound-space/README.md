# SOUND//SPACE

> Звук перестаёт исчезать и становится пространством, внутри которого можно ходить.

**Живое демо:** `/xrblocks/sound-space/` на GitHub Pages.

## Идея

После разрешения на микрофон живой FFT строит светящуюся ленту перед пользователем. Речь выглядит как нервный рельеф, музыка — как связная спектральная ткань, хлопок — как короткий белый удар с расходящимся кольцом.

Нажми или сделай pinch в нужный момент: текущая фраза замрёт отдельной 3D-скульптурой. Скажи «Staniverse», заморозь; скажи следующую фразу, заморозь ещё раз. Так вокруг появляется пространственная история последних минут. Quest позволяет пройти между слоями, телефон — обойти их камерой, десктоп — рассмотреть из simulator.

## Управление

- **MIC** — запросить микрофон;
- **tap / click / pinch / FREEZE** — сохранить текущий звуковой момент;
- **drag** — повернуть или переместить выбранную скульптуру;
- **hold / squeeze** — удалить выбранный слой;
- **стереть** — удалить всю историю.

Микрофонный поток остаётся внутри Web Audio API и никогда не записывается и не отправляется. Если доступ не выдан, демонстрационный генератор последовательно показывает речь, музыку и хлопок.

## Техника

Web Audio API → `AnalyserNode` → FFT → спектральная история → шейдерная сетка. Никакого сервера, AI или платного API. Геометрия и материалы переиспользуются; число сохранённых скульптур ограничено, чтобы опыт оставался лёгким для Quest 3.
