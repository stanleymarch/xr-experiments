# SOUND//SPACE

> Звук перестаёт исчезать и становится пространством, внутри которого можно ходить.

**Живое демо:** `/xrblocks/sound-space/` на GitHub Pages.

## Идея

После разрешения на микрофон живой FFT строит светящуюся ленту перед пользователем. Речь выглядит как нервный рельеф, музыка — как связная спектральная ткань, хлопок — как короткий белый удар с расходящимся кольцом.

Нажми или сделай pinch в нужный момент: текущая фраза замрёт отдельной 3D-скульптурой. Скажи «Staniverse», заморозь; скажи следующую фразу, заморозь ещё раз. FREEZE не затирает прошлое, а копит галерею: до пяти снимков, каждый новый встаёт на шаг правее предыдущего, старейшая вытесняется и гаснет. Свежий снимок почти спектральный, минутный — тёплый: тепло тинта и есть подпись возраста, а точный возраст выбранного снимка виден в статусе панели. Так вокруг появляется пространственная история последних минут. Quest позволяет пройти между слоями, телефон — обойти их камерой, десктоп — рассмотреть из simulator.

## Управление

- **MIC** — запросить микрофон; доступ спрашивается только по этому нажатию, потому что браузеры выдают его из жеста пользователя, а ранняя декларация задерживает старт опыта;
- **tap / click / pinch по пустому месту / FREEZE** — сохранить текущий звуковой момент; тап по скульптуре выбирает её (возраст и тембр снимка — в статусе панели);
- **drag тела скульптуры** — перенести её; **drag кольца у основания** — повернуть вокруг вертикали;
- **hold (~0.7 с, без сдвига) или squeeze** — растворить снимок, на котором держишь палец/луч (или выбранный): плинт раскаляется по мере удержания, потом скульптура гаснет и её геометрия освобождается;
- **CLEAR / «стереть»** — растворить всю историю разом.

Микрофонный поток остаётся внутри Web Audio API и никогда не записывается и не отправляется. Если доступ не выдан, демонстрационный генератор последовательно показывает речь, музыку и хлопок. При `?test=1` опыт стартует в automation-режиме XR Blocks: симулятор без рук и ретиклов, демо-генератор играет цикл речь→музыка→удар→тишина, поэтому сцена живая без микрофона, а галерея наполняется сама — по снимку каждые шесть секунд.

## Техника

Web Audio API → `AnalyserNode` → FFT → спектральная история → шейдерная сетка. Никакого сервера, AI или платного API. Живое поле скульптурируется каждый кадр, замороженные — один раз при freeze: их данные больше не меняются, и повторная запись вершин была бы чистой потерей кадров. Управление снимками — автоматическая манипуляция XR Blocks на самом объекте (перенос — surface-действие, поворот — отдельная ручка-кольцо), удержание и выбор идут через обычные фазы select-событий. Геометрия живого поля (32 частотные оси × 22 кадра истории) и пяти снимков галереи выбраны так, чтобы Quest 3 держал полный framerate с запасом.
